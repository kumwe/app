# ADR 0001: Clean Kumwe 2.0 baseline

- Status: Accepted
- Date: 2026-08-04

## Decision

Kumwe 2.0 is implemented as an independent application baseline in this
repository. It provides no Kumwe 1.x data migration, schema conversion,
compatibility layer, or undocumented PHP API compatibility.

The historical commit remains available in Git. Active 2.0 code is evaluated only
against the 2.0 product and quality contracts.

## Consequences

- The schema is designed for PostgreSQL without legacy compromises.
- Static factories, copied loaders and 1.x bootstrap files can be removed.
- Tests describe 2.0 behavior instead of characterizing obsolete behavior.
- Upgrade support begins with the first 2.x release.
