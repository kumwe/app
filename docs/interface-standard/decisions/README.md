# KIS compatibility decisions

This directory records accepted changes and defect corrections that affect the versioned Kumwe Interface
Standard. Each decision follows the proposal requirements in the [KIS version and change
policy](../README.md#version-and-change-policy) and the ownership rules in the [interface migration
governance](../programme/governance.md#kis-deviations-and-changes).

| Decision | Status | KIS version | Subject |
| --- | --- | --- | --- |
| [0001] | Accepted | `kis-1.0` retained | Scope ceilings and additive card identifiers |

The decision number identifies the governance record; it is not a substitute for the KIS version declared by
surfaces, templates, extensions, and stored preferences.
